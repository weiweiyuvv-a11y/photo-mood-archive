# Photo Mood Archive

Native iOS prototype for a local-first photo archive inspired by Instagram Archive.

## What is in this first cut

- SwiftUI iOS app project.
- PhotoKit permission flow and local photo loading.
- Month calendar that groups photos by capture date.
- Twelve seasonal doodle moods, one visual style per month.
- Transparent doodle by default, with a color spectrum mood picker per day.
- Day detail page with local photo thumbnails.
- Voice-first secret note using Speech + Microphone permissions, saved as editable text.

## Open it

Open `PhotoMoodArchive.xcodeproj` in Xcode, select an iPhone simulator or device, then run.
